
# Taxi Demand Analytics

## Project Description
Taxi Demand Analytics is a mini project used to analyze taxi trips, fare details, revenue and pickup and dropoff locations.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- Pandas

## Project Files
- index.html - Frontend
- app.py - Backend
- taxi_data.csv - Dataset
- requirements.txt - Required libraries

## Features
- Total Taxi Trips
- Average Fare
- Total Revenue
- Peak Hour Analysis
- Pickup and Dropoff Analysis
